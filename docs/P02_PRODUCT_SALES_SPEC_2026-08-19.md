# P02 一手箱 — Product / Sales Specification

Date: 2026-08-19
Branch: `product/p02-sales-ready`
Status: SALES PREP

## 1. Product

**商品名:** 一手箱

**一言:** 思いつきを捨てず、明日の具体的な一手へ落とすための、端末内完結型ミニ行動整理ツール。

一手箱は汎用メモアプリ、プロジェクト管理、AIチャットの代替を目指さない。商品価値は「思いつく → 箱へ入れる → 整理する → 明日の一手へ変える」を短い導線で完結させること。

## 2. Target

Primary:
- 思いつきは多いが、後で見返さず消える人
- ToDoアプリを作り込みすぎて続かない人
- 仕事・現場・個人の気づきをスマホで即保存したい人
- クラウドへメモ本文を預けたくない人

Not primary:
- チーム共同編集が必要な人
- 複雑なプロジェクト管理が必要な人
- 複数端末リアルタイム同期を必須とする人

## 3. Core Value

1. すぐ入れる
2. 後で整理できる
3. 明日の一手に変えられる
4. 端末内保存を基本とする
5. backup / import / exportで自己管理できる
6. PWAとしてホーム画面から使える

## 4. Differentiation

Google Keep等の汎用メモは多機能・同期・共有に強い。一手箱はそれらと機能数で競争せず、「行動へ変えるための箱」という目的の狭さを強みにする。

Todoist等のタスク管理は期限・プロジェクト・リマインダーなど管理機能に強い。一手箱は管理負荷を増やさず、思いつきから一手への変換に集中する。

## 5. Price

**500円（税込）買切り**を販売価格として採用する。

理由:
- 単機能PWAとして購入判断を軽くする
- 月額課金ほどの継続運営価値を現行機能に要求しない
- 無料汎用メモとの差は価格ではなく目的特化・端末内完結・導線で説明する

値上げ・バンドルは販売後データで再判定する。

## 6. Sales Method

初版は **Web販売 → PWA利用** を基本とする。

決済事業者、販売者情報、提供方法の最終URLは `OWNER_INFO_REQUIRED`。これらが未確定の間は購入ボタンを実決済へ接続しない。

## 7. Claims Policy

使用可:
- 端末内保存
- PWA
- backup / import / export
- 思いつき・明日の一手・買い物等を整理

使用禁止:
- 必ず成果が出る
- 絶対に忘れない
- データ消失しない
- 完全匿名
- 完全オフライン（外部font等の通信が残るため）

## 8. Data / PWA Explanation

メモ、設定、完了状態、ログ等はブラウザのlocalStorageへ保存する。運営独自サーバーへメモ本文を保存しない設計。ブラウザデータ削除・端末故障等で失われる可能性があるため、重要データはアプリ内backupを定期保存する。

PWAは対応ブラウザの「ホーム画面に追加」等から利用する。OS・ブラウザにより表示やインストール手順は異なる。
