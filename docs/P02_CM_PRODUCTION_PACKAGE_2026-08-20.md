# 一手箱 — CM Production Package

Status: **SCRIPT READY / NOT PUBLISHED**

## 6秒

- Hook: 「思いつきで終わらせない。」
- Visual: Drop入力 → 明日の一手 → ロゴ。
- Narration: 「思いつきを、明日の一手へ。一手箱。」
- CTA: 販売開始前は「詳細を見る」。価格・購入を断定しない。

## 15秒

- Problem: メモは増える。でも次に動く一手が決まらない。
- Demo: Dropへ預ける → 明日の一手へ整理。
- Benefit: 「全部を管理せず、次に動くことだけを見る。」
- CTA: 販売前「一手箱を知る」／販売承認後「500円買切り」。

## 30秒

- 0–5秒: 散らばったメモと迷い。
- 5–12秒: Dropへ短く記録。
- 12–20秒: 明日の一手、買う物、ひらめき整理の実画面。
- 20–25秒: 端末内保存とバックアップ導線。
- 25–30秒: ロゴ、LP、承認済みCTA。
- Narration: 「多機能なタスク管理を始めたいわけじゃない。浮かんだことを預け、必要なものだけ整理して、明日動く一手を一つ決める。一手箱。」

## 60秒

30秒構成に、ローカル保存、バックアップ／復元、総合タスク管理との違い、購入前確認を追加する。クラウド同期、確実な通知、自動AI整理など未実装機能を演出しない。

- 9:16: Reels / TikTok / Shorts、1:1: X、16:9: YouTube。

- screenshotsは実UIのみ。架空レビュー・架空売上・架空利用者は禁止。
- music/B-rollは自作または商用利用権の証拠がある素材だけを使う。
