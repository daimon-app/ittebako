# P02 一手箱 — SNS Sales Funnel

Date: 2026-08-19
Status: DRAFT / no public posting without owner approval

## Funnel

SNS short post / short video
→ LP `sales/index.html`
→ product fit / data explanation / FAQ
→ legal / privacy / support
→ purchase confirmation
→ payment
→ access / install guide
→ first-use onboarding

## Core Message

**思いつきを、明日の一手へ。**

汎用メモより「行動へ変える」ことに絞る。AI万能感、人生が変わる等の誇大表現は使わない。

## Short Video Concepts

### A. 15秒: 思いつき消失
1. 現場・移動中に思いつく
2. 後で思い出せない
3. 一手箱へ1行
4. 夜に整理
5. 明日の一手が1つ残る

CTA: 「思いつきを、明日の一手へ。」

### B. 15秒: ToDo疲れ
1. タスク管理を作り込む
2. 管理が仕事になる
3. 一手箱は入れる→整理→一手
4. 買切り500円

### C. 20秒: 端末内保存
1. メモ本文は運営独自サーバーへ保存しない設計
2. browser内保存
3. backupで自己管理
4. 自動同期なしも明示

## Post Copy Bank

- 思いついた時は覚えてる。夜には消えてる。だから、その場で箱へ。
- メモを増やすためじゃない。明日の一手を1つ決めるための箱。
- ToDoを管理しすぎない。思いつく → 入れる → 整理する → 一手にする。
- クラウド同期を前提にしない、端末内保存型の小さな行動整理ツール。

## Do Not Claim

- 絶対に行動できる
- 生産性が必ず上がる
- データが絶対消えない
- 完全匿名
- 完全オフライン
- Google Keep / Todoist等より優れていると断定

## Publication Gate

SNS公開投稿・広告出稿は本人承認 Required。リンク先LP、販売者情報、返金条件、決済導線が確定するまで購入CTAを有効化しない。
