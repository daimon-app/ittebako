# P02 一手箱 — FAQ / Support

Date: 2026-08-19

## FAQ

### 一手箱は何をするアプリですか？
思いつきや気づきをすぐ保存し、後から整理して「明日の一手」など具体的な行動へ変えるためのミニツールです。

### 普通のメモアプリとの違いは？
多機能なメモ管理ではなく、思いつきを行動へ変える短い導線に絞っています。

### 月額ですか？
販売価格は **500円（税込）の買切り**です。決済方法は販売開始前に確定します。

### データはどこに保存されますか？
メモ、設定、完了状態、ログ等は利用中ブラウザのlocalStorageへ保存します。運営独自サーバーへメモ本文を保存しない設計です。

### 機種変更すると自動で移りますか？
自動同期はありません。機種変更前にbackupを保存し、新端末でimportしてください。

### ブラウザデータを消したらどうなりますか？
保存データが失われる可能性があります。重要な内容は定期的にbackupしてください。

### backupとexportの違いは？
販売版の全量backupは、商品ID・schema version・作成日時とともに、メモや設定等の復元対象データを保存します。export/importの具体的な名称はアプリ画面の表記を優先します。

### オフラインで使えますか？
アプリ本体はService Workerによるキャッシュを備えています。ただし外部font等の通信要素があるため、販売文言では「完全オフライン」と断定しません。

### iPhone / Androidで使えますか？
PWA対応ブラウザから利用できます。ホーム画面追加手順や挙動はOS・ブラウザにより異なります。正式販売前の最終対応範囲は実機QA結果を優先します。

### Google Calendarへ勝手に送信されますか？
いいえ。Calendar連携は利用者が明示的に操作した場合だけ行う設計です。

### 返金できますか？
`OWNER_INFO_REQUIRED`。販売開始前に、決済方式とデジタル商品の提供形態に合わせて返金・キャンセル条件を明示します。

### 問い合わせ先は？
`OWNER_INFO_REQUIRED`。販売開始前に購入者が実際に連絡できる窓口を公開します。

## Support Intake

問い合わせ時に案内する情報:
- 一手箱のversion
- 端末名
- OS version
- browser名/version
- 問題が発生した画面
- 直前に行った操作
- 再現するか

原則としてメモ本文やbackup JSONを最初から送らせない。必要な場合のみ、個人情報・機密情報を削除した上で追加情報を依頼する。

## Common Recovery

1. 画面を再読み込み
2. ブラウザを再起動
3. Service Worker更新後は再読み込み
4. backupがある場合はアプリ内importを使用
5. browser storageを削除する前に必ずbackupを確認
