明日の一手へ。

一手箱は、思いつきや気づきをその場で入れて、あとから整理し、具体的な一手へ変えるための小さな行動整理ツールです。

500円（税込）・買切り

広告なし。月額課金なし。メモ本文は運営独自サーバーへ保存しない設計です。

購入前の確認内容を見る

メモを増やすためではなく、動くため。

高機能なメモアプリやタスク管理を作り込むほど、入力と整理そのものが仕事になることがあります。一手箱は「入れる → 整理する → 明日の一手にする」に絞っています。

できること

  • 思いつき・気づきをすぐ保存
  • 保存内容を検索・整理
  • 明日の一手として具体化
  • 買い物・帰宅後など用途別に扱う
  • backup / import / export
  • PWAとしてホーム画面から利用

3ステップ

  1. 浮かんだら、一手箱へ入れる
  2. 落ち着いた時に整理する
  3. 明日やる具体的な一手を決める

データについて

メモ、設定、完了状態、ログ等は利用中ブラウザのlocalStorageへ保存します。ブラウザデータ削除や端末故障で失われる可能性があるため、重要データは定期的にbackupしてください。複数端末の自動同期はありません。

向いている人

思いつきが多い人、ToDo管理を複雑にしたくない人、現場や仕事中の気づきをスマホで素早く残したい人、クラウドへメモ本文を預けず自己管理したい人。

向いていない人

チーム共同編集、複雑なプロジェクト管理、複数端末リアルタイム同期を必須とする人には、汎用メモ・タスク管理サービスの方が適しています。
